Инструкция по установке на устройства

Пошаговое руководство по установке и первой настройке для Android и iOS:

Шаг 1

1. Скачивание установочного пакета

Нажмите «Скачать для Android» или отсканируйте QR-код смартфоном. Файл загрузится в папку «Загрузки».

Шаг 2

2. Разрешение установки из внешних источников

При открытии файла система безопасности Android может запросить разрешение. Нажмите «Настройки» и включите тумблер «Разрешить установку из этого источника».

Шаг 3

3. Выдача системных прав телеметрии

Android может запросить разрешение для отдельных функций. Перед выдачей прочитайте системный запрос; разрешения сами по себе не означают, что данные радиосети передаются в веб-отчёте.

Шаг 4

4. Автономная фоновая работа

Работа в фоне зависит от настроек Android, ограничений аккумулятора и доступности сети. Проверьте разрешения приложения и настройте фоновые ограничения так, как вам удобно.

Шаг 1

1. Загрузка установочного пакета

Используйте актуальную ссылку и инструкции владельца; способ установки зависит от доступной сборки.

Шаг 2

2. Проверьте источник приложения

Используйте инструкцию владельца проекта для текущей сборки. Перед установкой проверьте источник файла и издателя.

Шаг 3

3. Локальный журнал

В проверенной версии клиента журнал активности хранится на устройстве и не отправляется в веб-аудит.

Шаг 4

4. Что не подтверждено

Live Activities, SIM-виджет и скорость в реальном времени в этой версии не подтверждены.

XYLEN PLATFORM

О платформе

Xylen объединяет Android-клиент и веб-панель для просмотра событий приложения и счётчиков сотовой загрузки, которые клиент отправил с согласия пользователя.

Назначение платформы

Панель помогает владельцу увидеть зарегистрированные Android-устройства, недавние отчёты, дневные счётчики и действия, сообщённые приложением. Публичная часть показывает только агрегированные сведения.

Как устроен обмен данными

После согласия Android отправляет JSON-отчёт в /api/audit по HTTPS. Cloudflare Pages Function принимает его; постоянное хранение использует настроенный KV binding. Подробные записи доступны после проверки Cloudflare Access и email владельца.

Границы возможностей

Сайт показывает значения, сообщённые клиентом, и не проверяет их независимо. Он не измеряет скорость радио в реальном времени и не получает данные о вышках. Изученный исходный код iOS хранит журнал локально и не отправляет его в этот веб API.

XYLEN PLATFORM

Конфиденциальность

Здесь описан поток данных в изученных версиях сайта и мобильных клиентов. Это техническая информация, а не юридическое заключение; оператор должен определить применимые требования и основания обработки.

Данные Android-отчёта

После согласия Android отправляет ID установки, модель, имя тестировщика, экран, действие и детали, оператора, дневные и сессионные счётчики, а также сведения об активных или использованных сегодня SIM-профилях. Значения сообщает клиент, сервер не проверяет их независимо.

Что не передаётся в веб-аудит

Веб audit API не получает номера телефона, ICCID, IMSI, идентификаторы вышек или измерения радиосигнала. Изученный код iOS хранит журнал на устройстве. Отдельный Android portal API может передавать данные на другой сервис при настройке.

Назначение и доступ

Публичный endpoint возвращает агрегированные числа и сотовые счётчики. Подробные записи требуют проверки Cloudflare Access и соответствия email владельца.

Хранение и удаление

Сервер хранит последнюю запись устройства до удаления оператором; журнал ограничен последними 200 событиями. Отзыв согласия прекращает будущую отправку, но сам по себе не удаляет уже сохранённые записи.

Защита и правовые сведения

Передача идёт по HTTPS. Оператору следует проверить применимость Закона Республики Узбекистан № ЗРУ-547 «О персональных данных», UK GDPR и Data Protection Act 2018. Эта страница не подтверждает соблюдение законодательства, расположение хранилища или шифрование данных на сервере.
